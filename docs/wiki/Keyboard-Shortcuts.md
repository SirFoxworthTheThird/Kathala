# Keyboard Shortcuts

The **Help** panel (the **?** icon, top-right) lists these in the app too, alongside in-app explanations of each concept — the time cursor, snapshots, timelines, maps, playback, and the rest.

---

## Global

| Shortcut | Action |
|---|---|
| **Ctrl/⌘+K** | Open the [search](Search) palette |
| **Ctrl/⌘+Z** | [Undo](Undo-and-Redo) — outside a text box |
| **Ctrl/⌘+Shift+Z** or **Ctrl+Y** | Redo |
| **Esc** | Close any panel, modal, or lightbox; cancel an inline edit |

> Inside a text box, **Ctrl/⌘+Z is your browser's own undo**, working letter by letter. PlotWeave deliberately stays out of the way there.

[Reading mode](Reading-Mode) unbinds undo and redo along with removing their buttons.

## Chapter bar (the time cursor)

| Interaction | Action |
|---|---|
| Click a chapter segment | Jump to that chapter's first event |
| Click an event tick | Set that event as the cursor |
| **◀ / ▶** | Move one event back or forward |
| **✕** | Clear the cursor back to *All chapters* |
| **Play / Pause / Stop** | [Story Playback](Story-Playback) on the map |
| Speed control | Cycle playback speed |
| **Compare** | Open the [Chapter Diff](Chapter-Diff) |
| Mouse wheel over the bar | Scroll the track horizontally |

---

## Timeline page

| Interaction | Action |
|---|---|
| **Shift+click** an event checkbox | Select a range |
| Drag a chapter row | Reorder the narrative |
| Drag an event card | Reorder within its chapter |

---

## Corkboard

| Interaction | Action |
|---|---|
| Drag a card within a column | Reorder scenes in that chapter |
| Drag a card to another column | Move the scene to that chapter |
| Click a card's title | Open the scene with the cursor set to it |

---

## Map

| Interaction | Action |
|---|---|
| Scroll wheel | Zoom |
| Drag | Pan |
| **+ Location**, then click | Place a marker |
| **Right-click** the canvas | Add a location or label, or begin a route or region there |
| Click a marker | Open the location detail panel |
| Click a character pin | Open their film strip and panel |
| Drag a character from the sidebar | Place them at a location |
| Tap a character's crosshair, then a location | The same, on a touch device |
| Drag a map onto another in the layers tree | Nest it as a sub-map |
| Press and hold a map (touch) | Pick it up to re-parent, so a swipe still scrolls |
| **Esc** | Back out of any placing or drawing mode |

---

## Relationship graph

| Interaction | Action |
|---|---|
| Scroll wheel | Zoom |
| Drag the background | Pan |
| Click a node | Highlight that character's edges |
| Click an edge | Open the relationship editor |
| Drag from node to node | Create a relationship |

## Character Arc grid

| Interaction | Action |
|---|---|
| Click a column | Set that moment as the time cursor |
| Click a cell | Expand it for the full notes |

## Search palette

| Key | Action |
|---|---|
| **↑ / ↓** | Move between results |
| **Enter** | Open the selected result |
| **Esc** | Close without navigating |

---

## Focus mode

| Key | Action |
|---|---|
| **Esc** | Leave focus mode and return to the event |

---

## Image lightbox

| Interaction | Action |
|---|---|
| Click a portrait, item image, world cover, or location picture | Open it full size |
| **Esc**, click the backdrop, or ✕ | Close |
| Click the picture itself | Nothing — so you can lean in without losing your place |
